📷 Đọc QR/Barcode

📷 Kéo-thả ảnh chứa QR/Barcode vào đây, dán (Ctrl+V), hoặc bấm để chọn
Lịch sử đã đọc (phiên này):
Hỗ trợ QR code và các barcode 1D phổ biến (EAN-13, EAN-8, Code 128, Code 39, UPC-A, ITF...). Ảnh mờ/nghiêng/độ tương phản thấp có thể không đọc được — thử chụp lại rõ nét hơn. Xử lý hoàn toàn trên trình duyệt, không upload ảnh đi đâu.
