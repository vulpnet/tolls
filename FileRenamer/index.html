📁 Đổi Tên File Hàng Loạt

⚠️ Chỉ hoạt động trên Chrome/Edge (File System Access API — Firefox/Safari không hỗ trợ). Cơ chế đổi tên là đọc nội dung file cũ → ghi ra file mới → xoá file cũ (không phải đổi tên tức thời thật sự), vì trình duyệt hiện chưa hỗ trợ rename trực tiếp cho file thật trên đĩa. File cũ chỉ bị xoá sau khi file mới đã ghi xong và kiểm tra đúng kích thước — nhưng vẫn nên sao lưu trước nếu là dữ liệu quan trọng. Không xử lý thư mục con (chỉ đổi tên file trực tiếp trong thư mục đã chọn).
