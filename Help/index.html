ℹ️ Hướng dẫn sử dụng

Tổng hợp toàn bộ công cụ trong hệ thống — mỗi tool chạy hoàn toàn trên trình duyệt, không cần cài đặt, không gửi dữ liệu lên server.

💡 Tất cả tool đều tự lưu không cần đăng nhập. Dữ liệu bạn nhập (text, ảnh, file) chỉ xử lý ngay trên máy bạn — không upload đi đâu, trừ khi tool có ghi rõ ngược lại (ví dụ Excel → Table khi tải từ Google Sheet sẽ gọi tới Google để lấy dữ liệu công khai của sheet đó).

Mục lục nhanh

🔄 Convert (7) 🛠️ Tiện ích (13) 🎮 Games (3)

🔄 Convert

Compare Text

So sánh 2 đoạn văn bản, hiển thị điểm khác nhau (diff) theo dòng và theo từ.

Dán bản gốc và bản sửa vào 2 ô, kết quả hiện ngay bên dưới với màu đỏ/xanh đánh dấu phần bị xóa/thêm.
JSON Convert

Chuyển JSON string qua lại giữa 3 dạng: Pretty (định dạng đẹp có tô màu), Minify (nén 1 dòng), Table (bảng, hỗ trợ xem chi tiết object/array lồng nhau).

Dán JSON vào ô input, chọn tab tương ứng. Ở chế độ Table, bấm vào ô chứa object/array để xổ thêm bảng con.
Excel → TableSheetJS

Đọc file Excel/CSV hoặc link Google Sheet công khai, hiển thị dạng bảng có thể lọc theo cột, kéo-thả đổi thứ tự cột, và tạo Pivot Table (kéo-thả field vào vùng Hàng/Cột/Giá trị, click vào ô kết quả để xem dữ liệu gốc).

Kéo-thả file vào hoặc dán link Google Sheet (cần share "Anyone with link can view"). Bấm nút 📐 Pivot để mở bảng tổng hợp.
Image → TextTesseract.js

OCR (nhận diện chữ trong ảnh) sang text, hỗ trợ Tiếng Việt và Tiếng Anh.

Kéo-thả ảnh, dán ảnh (Ctrl+V), hoặc chọn file. Chọn ngôn ngữ phù hợp rồi bấm "Nhận dạng text". Lần đầu chạy sẽ hơi chậm vì cần tải dữ liệu ngôn ngữ.
Table BuilderSheetJS

Tạo bảng dữ liệu từ đầu, giống spreadsheet: thêm/xóa hàng-cột, mỗi cột chọn kiểu Text/Number/Date để tự kiểm tra dữ liệu nhập vào.

Bấm ô để sửa trực tiếp, hoặc copy dữ liệu từ Excel rồi Ctrl+V vào 1 ô để dán cả khối. Xuất ra Excel/CSV/JSON.
PDF → Text/Imagepdf.js

Trích toàn bộ text từ file PDF, hoặc xuất từng trang PDF thành ảnh PNG để tải về.

Kéo-thả file PDF vào, chọn tab "Trích Text" hoặc "Xuất ảnh từng trang".
Merge/Split PDFpdf-lib

Gộp nhiều file PDF thành 1 (sắp xếp lại thứ tự bằng nút ↑↓), hoặc tách trang theo phạm vi tùy chọn (ví dụ 1,3,5-8) hoặc tách toàn bộ thành từng file riêng.

Chọn tab Gộp hoặc Tách, kéo-thả file vào, làm theo hướng dẫn trên màn hình.
Markdown Convertermarked + turndown

Chuyển Markdown → HTML (xem trước trực tiếp, xuất file .doc mở được trong Word), hoặc HTML → Markdown.

Chọn tab tương ứng, gõ/dán nội dung vào ô input, kết quả hiện ngay bên phải. Bấm "Tải file Word" để xuất .doc.

🛠️ Tiện ích

🔳 QR Codeqrcode-generator

Tạo mã QR từ text hoặc link, tùy chỉnh màu sắc, kích thước, mức sửa lỗi.

Nhập nội dung, tùy chỉnh rồi tải PNG hoặc copy ảnh trực tiếp vào clipboard.
🔤 Case Converter

Chuyển đổi 12 kiểu viết hoa/thường: UPPERCASE, lowercase, Title Case, camelCase, PascalCase, snake_case, kebab-case, dot.case, đảo ngược ký tự...

Nhập text, bấm vào kiểu muốn chuyển, kết quả hiện bên dưới kèm nút copy.
📋 Text ↔ CSV/TSV

Chuyển text có cấu trúc (phân cách bằng Tab/phẩy/chấm phẩy/ký tự tùy chọn) thành bảng xem trước, và ngược lại.

Dán text vào ô trái, chọn đúng delimiter, bảng bên phải tự cập nhật. Dùng nút "Đảo chiều" để chuẩn hóa về dạng TSV (dán thẳng vào Excel).
🔍 Duplicate Finder

Tìm các dòng trùng lặp trong danh sách, tô màu phân biệt dòng trùng (đỏ) và dòng duy nhất (xanh).

Dán danh sách vào, có thể bật "Không phân biệt hoa/thường". Dùng nút "Xóa trùng (giữ 1 bản)" để dọn sạch danh sách ngay.
📐 Unit Converter

Đổi đơn vị đo: độ dài, khối lượng, diện tích, thể tích, tốc độ, nhiệt độ, dung lượng dữ liệu. Không có tiền tệ vì tỷ giá luôn biến động, không thể đảm bảo chính xác.

Chọn nhóm đơn vị, nhập giá trị, kết quả và bảng quy đổi nhanh hiện ngay bên dưới. Nút ⇄ để đảo chiều 2 đơn vị.
📝 Word Counter

Đếm số từ, ký tự, câu, đoạn văn; ước tính thời gian đọc/nói; liệt kê top 10 từ xuất hiện nhiều nhất.

Gõ hoặc dán văn bản, tất cả số liệu tự cập nhật khi bạn gõ.
✉️ Mail Merge

Điền hàng loạt template chứa {{TenCot}} bằng dữ liệu dán từ Excel (dòng đầu là tên cột).

Viết template ở ô trái (dùng {{TenCot}} để đánh dấu chỗ cần điền), dán bảng dữ liệu vào ô dưới. Dùng nút ‹ › để xem trước từng bản ghi, hoặc "Xuất tất cả" để lấy toàn bộ cùng lúc.
📅 Date Calculator

3 chức năng: tính khoảng cách giữa 2 ngày (có thể loại T7/CN), cộng/trừ số ngày vào 1 mốc, tính tuổi chính xác.

Chọn tab tương ứng, nhập ngày vào ô lịch, kết quả hiện ngay lập tức.
🔐 Password Generator

Sinh mật khẩu ngẫu nhiên an toàn (dùng crypto ngẫu nhiên thật của trình duyệt), tùy chỉnh độ dài và loại ký tự, đo độ mạnh.

Kéo thanh trượt chỉnh độ dài, tick chọn loại ký tự. Bấm 🔄 để tạo lại, 📋 để copy. Nút "Tạo hàng loạt" sinh 10 mật khẩu cùng lúc.
🔒 Hash & Encode

Tính hash SHA-1/SHA-256/SHA-512 (một chiều, không giải mã ngược được), Base64 encode/decode, URL encode/decode.

Nhập text vào ô input, tất cả kết quả hiện đồng thời bên dưới, mỗi ô có nút Copy riêng.
🎨 Color Picker

Chọn màu và xem ngay mã HEX/RGB/HSL, kèm bảng màu liên quan (đậm/nhạt cùng tông) và màu bổ sung (complementary/triadic/analogous) để phối màu.

Bấm ô màu để chọn, hoặc bấm vào 1 ô trong bảng màu gợi ý để đổi màu chính sang màu đó.
🎲 Lorem Ipsum

Sinh đoạn văn giả (Lorem Ipsum — văn bản placeholder kinh điển trong thiết kế) theo số lượng đoạn/câu/từ tùy chọn, và dữ liệu giả (họ tên, email, số điện thoại, địa chỉ kiểu Việt Nam) để test form/database.

Chọn tab tương ứng, chỉnh số lượng rồi bấm "Tạo". Dùng khi cần nội dung mẫu nhanh mà không muốn nghĩ nội dung thật.

🎮 Games

🪢 Tug of War

Game kéo co bash phím — 2 người chung bàn phím hoặc đấu với AI (3 mức độ khó).

2 người: P1 dùng A/D, P2 dùng ←/→. Đấu AI: dùng Space hoặc bấm nút BASH trên màn hình. Bash càng nhanh, dây càng kéo về phía bạn.
⭕❌ Caro / Gomoku

Cờ caro/gomoku với 3 chế độ: 2 người chung màn hình, đấu AI (bất khả chiến bại ở bàn 3×3 mức Khó), hoặc Online — tạo/vào phòng chờ để chơi với người khác qua mạng (kèm quick-chat emoji dựng sẵn).

Chọn kích thước bàn (3×3 hoặc 15×15 Gomoku) và chế độ chơi. Ở mode Online, đặt tên hiển thị rồi tạo phòng mới hoặc chọn 1 phòng đang chờ trong danh sách.
🥋 Fight Game

Game đối kháng võ thuật đơn giản trên canvas — di chuyển, nhảy, đánh thường/mạnh, đỡ đòn.

2 người: P1 dùng A/D/W/F/G/S, P2 dùng ←/→/↑/K/L/↓. Đấu AI: chỉ cần điều khiển P1, chọn độ khó trước khi bắt đầu.
